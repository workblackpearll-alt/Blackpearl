# Black Pearl Hero Background Video

Place your background video file in this folder:
- Recommended filename: lady-alice.mp4
- Recommended format: MP4 (H.264 video codec, AAC audio or muted)
- Recommended resolution: 1080p (1920x1080) or 4K, compressed for web (under 20-30MB)
- Path configured in index.html: /assets/videos/lady-alice.mp4

The video will automatically autoplay muted on a loop behind the cinematic dark scrim on the hero section.
While no video file is present, the hero page automatically uses the high-res evening poster image (/assets/images/lady-alice-night.jpg).
