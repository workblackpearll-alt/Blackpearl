# Black Pearl · Lady Alice — Endpoint Security Matrix

| Endpoint | Method | Public / Auth | Authorization Requirements | Input Validation | Sensitive Data Handled | External Services | Security Controls | Test Outcome |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| `/api/create-order` | POST | Public | None | Strong: Slot, duration, start hour, date ISO (>= today), name, phone (>=10 digits), email regex, guests (1-100) | Guest PII (name, phone, email, notes) | Supabase Admin, Razorpay API | Server calculates price & deposit; checks range availability in Supabase; generates cryptographically random 192-bit verify token | **FAIL** (Unthrottled; vulnerable to slot-locking DoS — BP-SEC-05) |
| `/api/verify-payment` | POST | Public | Cryptographic HMAC Signature | Required orderId, paymentId, signature strings | Payment ID, verify token, booking confirmation | Razorpay HMAC check, Supabase Admin, Resend API | Validates HMAC-SHA256 signature using `crypto.timingSafeEqual`; atomic email lock (`email_sent_at IS NULL`); database EXCLUDE constraint handling | **PASS** (Cryptographically verified and idempotent) |
| `/api/availability` | GET | Public | None | None (calculates from current India date) | Only occupied date ranges: `[{ date, start, end }]` | Supabase Admin | Returns zero customer PII; only returns numerical 24h hour occupied ranges | **PASS** (Privacy-preserving calendar queries) |
| `/api/booking` | GET | Public with Token | Requires `code` + 192-bit `t` (verify token) | Validates code and token presence; timingSafeEqual token comparison | Passenger name, occasion, date, slot, guests, price, deposit, phone, email, notes | Supabase Admin | Timing-safe verification token matching; prevents enumeration of booking codes without token | **PARTIAL** (Tokens are cryptographically secure, but returns excessive PII to dock staff — BP-SEC-08) |
| `/api/qr` | GET | Public with Token | Requires `code` + 192-bit `t` (verify token) | Validates code and token presence | PNG QR code buffer pointing to `/verify` | Supabase Admin, QRCode generator | Generates dynamic PNG QR without third-party leak; requires valid verify token | **PASS** (Self-hosted QR generation with token protection) |
| `/api/payment-failed` | POST | Public | None | orderId string, abandoned boolean, reason string | Order ID, failure reason | Supabase Admin | Rejects downgrade of paid bookings (`allowedFrom = [pending, failed, abandoned]`); only records failure reason | **PASS** (State downgrade prevented) |
| `/api/razorpay-webhook`| POST | Public with Signature | HMAC-SHA256 via `X-Razorpay-Signature` | Verifies raw body signature | Payment entity, order entity, payment status | Razorpay Webhook Secret, Supabase Admin, Resend API | Validates raw body HMAC signature; idempotent payment marking; atomic confirmation email dispatch | **PASS** (Robust signature and duplicate prevention) |
